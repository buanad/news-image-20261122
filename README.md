A make.fun Growth bounty entry: one 1024×1024 image summing up Sunday 22 November 2026's world news — 31 stories from 7 regions. Every story carries a confidence chip (CF = confirmed, RP = reported, CL = one side's claim) and a UTC time, plus a "THE DAY IN UTC" strip, a world map, and a DATE CHECK footer naming what was deliberately left out because it broke before 22 November. Lead story: Iran strikes US bases in Bahrain (Al Jazeera, CONFIRMED, overnight).

`main.py` (Python standard library only) copies `entry.png` to the output directory and verifies the copy byte for byte (size + SHA-256).
